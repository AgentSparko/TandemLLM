\partintro{%
TandemApp is the dashboard, the proxy in front of engines and cloud APIs, the Chat tab and TandemNode, its agent on each machine. It runs no model itself. Chapter~\ref{ch:install-app} installs it on any machine, Chapter~\ref{ch:other-engines} puts other engines and cloud APIs behind it, Chapter~\ref{ch:dashboard} goes through the page view by view, Chapter~\ref{ch:chat} is the Chat tab (in beta) with its sandbox and permission modes, and Chapter~\ref{ch:hosts} watches several engines at once. The engine and its own API are in the engine's manual.}
