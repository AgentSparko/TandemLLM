\chapter{Reference}\label{ch:ref-app}

Every table in this chapter is generated from TandemApp's code by \code{manual/tools/gen_reference.py}, and \code{gen_reference.py --check} fails while one is stale. The HTTP tables are written by hand in \code{manual/tools/http_ref.py} and checked against the code: a route the controller's handlers test, a header name or an error type the code uses that is missing here, or a row the code no longer has, fails the check. The engine's flags, switches, routes and metrics are in \enginemanual{Reference}.

\section{Variables and knobs}\index{TANDEM variables}

The proxy, the collector and the plugins read \code{TANDEM_*} variables. TandemApp's code reads some of the engine's \code{QSE_*} variables too, where it starts chatd, runs TandemNode or reads the engine's files. Inside an engine the conductor reads the \code{QWEN38_*} knobs the engine contract names (\code{contracts/engine-ext-v1/knobs.json}), with the defaults of \code{tandemapp/knobs.py}.
